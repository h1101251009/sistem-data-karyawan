# Sistem Data Karyawan (K8)

UAS Praktikum Pemrograman Web Dasar - Program Studi Sistem Informasi, Universitas Tanjungpura.

## Fitur

- Daftar karyawan (tabel Bootstrap)
- Tambah, edit, hapus (modal)
- Search nama/NIP, filter departemen dan status, sort
- Validasi form dengan jQuery
- Total gaji karyawan aktif

## Teknologi

HTML5, CSS3, Bootstrap 5, jQuery (tanpa backend dan database)

## Cara menjalankan

Buka `index.html` di browser.
